## ثالثًا: كيف تربط مهارة معي — ثلاث طرق

### الطريقة 1: معي مباشرةً — لا تثبيت إطلاقًا (الأسهل)

**المهارة ليست برنامجًا، بل ملف تعليمات.** لذلك لا حاجة لتثبيت شيء في نظامي —
أعطني الرابط، أستنسخه، أقرأ `SKILL.md`، وأشتغل به في نفس الجلسة.

اكتب لي مثلًا:

```
استنسخ https://github.com/Leonxlnx/taste-skill واشتغل به
على موقع لمطعم لبناني في بيروت
```

أو ببساطة:

```
هذه المهارة: <الرابط> — ركّبها وطبّقها على موقعنا
```

أو استخدم صيغة الطلب الجاهزة:

```
https://github.com/nextlevelbuilder/ui-ux-pro-max-skill

اقرأ هذه المهارة وطبّقها على الموقع الذي نبنيه، ثم قل لي ماذا غيّرت.
```

**ماذا أفعل أنا بالضبط:** أستنسخ المستودع، أقرأ الملفات، أنفّذ منهجها على مشروعك،
وأخبرك بالنتيجة. وأثبّت أي حزمة يحتاجها عبر `npm` أو `pip`.

### الطريقة 2: على جهازك في Claude Code — عبر المتجر

```
/plugin marketplace add obra/superpowers-marketplace
/plugin install superpowers@superpowers-marketplace

/plugin marketplace add secondsky/claude-skills
/plugin install tailwind-v4-shadcn@claude-skills

/plugin marketplace add anthropics/claude-plugins-official
/plugin install frontend-design@claude-plugins-official
```

### الطريقة 3: على جهازك — نسخ يدوي (يعمل مع أي أداة)

```bash
git clone --depth 1 https://github.com/anthropics/skills.git
cp -r skills/skills/frontend-design   ~/.claude/skills/
cp -r skills/skills/brand-guidelines  ~/.claude/skills/

# لكل المشروع بدل كل المستخدمين:
mkdir -p .claude/skills && cp -r ... .claude/skills/
```

أو: الصق الرابط في محادثة Claude واكتب «ثبّت هذه المهارة، ثم أكّد أنها تعمل».

### الطريقة 4: الـ17 جاهزة من هذا المستودع

```bash
git clone https://github.com/n8nlearn350/arena-skill.git
cd arena-skill/web-skills
./install.sh              # في المشروع الحالي
./install.sh --global     # لكل المشاريع
```

المثبِّت **لا يستبدل** مهارة موجودة عندك بنفس الاسم.

## رابعًا: تحذيرات مهمة

1. **لا تضع مفاتيح API في المحادثة.** بعض المهارات تحتاج مفاتيح (مثل
   `deploy-to-vercel`, `bria-ai`). ضعها في ملف في `.gitignore` خارج المستودع،
   ودوّرها بعد الانتهاء.
2. **المهارة = تعليمات، وقد تكون ضارة.** راجع `SKILL.md` قبل التثبيت؛ أي مهارة
   تقرأ ملفاتك وتشغّل أوامر. استخدم
   [skill-security-auditor](https://github.com/alirezarezvani/claude-skills)
   لفحصها.
3. **النجوم ≠ الجودة.** 295 ألف نجمة لا تعني أنها مناسبة لمشروعك.
4. **الصلاحيات:** كل ملف يكتبه الوكيل قد يحتاج موافقة. شغّل Claude Code في
   وضع accept-edits لتسريع الأمر.

## خامسًا: ما لا أستطيع فعله

- **لا أستطيع إضافة أدوات جديدة إلى سبلتي.** المهارة تعطيني *منهجية*، لا أدوات.
  لذا مهارة تعتمد على خدمة خارجية تحتاج مفتاحًا واتصالًا.
- **لا متصفح ولا وكلاء متعددون هنا.** المهارات التي تحتاج Playwright أو أداة
  `Task` لا تعمل في هذه البيئة، وتعمل على جهازك.
- **الشبكة محدودة عندي.** PyPI و npm و GitHub متاحة؛ خدمات أخرى قد لا تكون.
